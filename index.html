03ATLAS · Run-3 LLP · MSVtx

Mapping the loss landscape

Latent Activation Topology of Hidden Embeddings

LATHE measures the geometry a trained classifier sits in: how sharp its basin is, where the BCE and α·DisCo terms pull against each other, and whether two seeds landed in the same valley. It then asks one question: does that geometry predict held-out ABCD closure better than the loss settings alone?

LATHE describes and maps. Any optimization that uses the map belongs to TRUSS, and only if the kill test passes. Otherwise LATHE would be grading its own exam.

01Definition

What a fingerprint is

A fixed set of geometric measurements, taken at fixed points in training (epochs 1, 5, 10, 20, final) or on a saved checkpoint, always on the same held-out probe batch. Each run becomes one row: settings in, fingerprint in the middle, final metrics out.

H2

Gradient conflict, per layer

\(c_\ell = \cos(g_B, g_D)\)   \(\rho_\ell = \alpha\lVert g_D\rVert / \lVert g_B\rVert\)
\(\kappa_\ell = \dfrac{\lVert g_B + \alpha g_D\rVert}{\lVert g_B\rVert + \alpha\lVert g_D\rVert}\)

Direction, balance and cancellation of the two terms in each layer. A layer that stalls (κ small, ρ near 1) through training is a pinch-point candidate.

H1 · H3

Hessian spectrum ends

\(\lambda_{\max},\; \lambda_{\min},\; \operatorname{tr} H\)

Sharpness and negative curvature by (shifted) power iteration; the trace by Hutchinson. Tracked over epochs, it shows whether there is an early curvature spike.

H1

1-D filter-normalized slices

\(\Delta L(a) = L(\theta^* + a\,d) - L(\theta^*)\)

Rise, width and roughness of the basin along random filter-normalized directions (Li et al. 2018), so basins can be compared across α.

H4

Seed-pair interpolation

\(B_{AB} = \max_t\,\big[L(t) - \text{chord}(t)\big]\)

The loss bump on the straight line between two seeds' weights, plus a permutation-free prediction distance. Is a degraded seed in a separate basin?

DisCo

dCor gap

\(\mathbb{E}_{\text{mb}}\big[\mathrm{dCor}^2\big] - \mathrm{dCor}^2_{\text{full}}\)

DisCo is a batch statistic. If minibatches see more dependence than the full background sample, training optimizes a biased version of the target.

KILL

From fingerprint to verdict

\((\phi, A, \text{fold}, \text{seed}) \to F_{t_1},\dots,F_{\text{final}} \to M_{\text{final}}\)

The thesis is testable: a fingerprint is a better intermediate representation than the raw settings φ if it predicts the final metrics better, and that should carry over across architectures.

Leakage guard. Final per-term losses are recorded but tagged loss_* and kept out of the kill-test features: "the final DisCo value predicts closure" is already known and is not a landscape finding. Map events and closure events are disjoint. Validity of the pinch-point scores: pinch-point notes →

04How it runs

From checkpoint to site

Adapter

Copy and fill the template: model factory, checkpoint path, probe batch, loss terms.

adapters/TEMPLATE.py

Probe

Fingerprint saved checkpoints, then seed pairs within each cell. No training.

lfp probe · lfp pairs

Record

Hook new training runs at chosen epochs. Verified bit-for-bit identical to training without it.

FingerprintRecorder

Build

Aggregate fingerprints and the ledger into the static explorer. Opens from disk.

lfp build-site --out explorer

Preview

Exploratory kill test on design data: ridge, CV grouped by seed, permutation null.

lfp killtest

Things that will bite

  • Permutation symmetry. Barriers between unaligned seeds are above zero even for equivalent solutions. Compare groups of pairs.
  • Negative curvature is expected on a held-out probe batch. Its size by cell is the signal.
  • DisCo must be twice differentiable. cdist/sqrt at zero distance gives NaN Hessian-vector products; lfp flags it.
  • dCor convention. Probes return dCor². If training penalizes dCor, call set_dcor_squared(False).
  • α = 0 runs still report conflict: the pull DisCo would exert, at zero weight.
  • Cost. Hessian probes dominate. Time one run (timing_s) before launching many.
